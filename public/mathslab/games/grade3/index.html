Grade 3 lesson games

Ten Grade 3 maths games, one per objective. Every game is built from the same Fikr lesson-game template as Grades 1 and 2: Rawi the guide, Ghubar the mischief-maker, guided Learn slides, CUBES think-first on every word problem, a three-step hint ladder, and three CRA levels — now working with equal groups and arrays, times tables, fractions on a number line, equivalent fractions, area, perimeter and rounding.

Prototypes for review — not curriculum-approved and not classroom-tested. Objective mapping and the evidence boundary are recorded in docs/mowazi/g3-expansion.md.

Each game is one self-contained offline HTML file in this folder. No network, no external fonts, no images — artwork is inline SVG drawn in the page.

Grade 2 lesson games

Ten Grade 2 maths games, one per objective. Every game is built from the same Fikr lesson-game template as Grade 1: Rawi the guide, Ghubar the mischief-maker, guided Learn slides, CUBES think-first on every word problem, a three-step hint ladder, and three CRA levels — now working to 1,000 with regrouping, riyals, arrays, five-minute time and a graph key.

Prototypes for review — not curriculum-approved and not classroom-tested. Objective mapping and the evidence boundary are recorded in docs/mowazi/g2-expansion.md.

Each game is one self-contained offline HTML file in this folder. No network, no external fonts, no images — artwork is inline SVG drawn in the page.

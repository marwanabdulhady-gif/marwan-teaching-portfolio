Grade 1 lesson games

Ten Grade 1 maths games, one per step of the Grade 1 sequence. Every game is built from the Fikr lesson-game template: Rawi the guide, Ghubar the mischief-maker, guided Learn slides, CUBES think-first on every word problem, a three-step hint ladder, and three CRA levels.

Prototypes for review — not curriculum-approved and not classroom-tested. Objective mapping and the evidence boundary are recorded in docs/mowazi/g1-expansion.md.

Each game is one self-contained offline HTML file in this folder. No network, no external fonts, no images — artwork is inline SVG drawn in the page.

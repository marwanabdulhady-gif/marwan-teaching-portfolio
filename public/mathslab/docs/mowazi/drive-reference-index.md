# Mowazi Drive source index

This repository received a **curated, text-based design/scope reference** from the Drive folder below. The full archive remains in Drive; this index is not a copy of every file. The folder contains curriculum records, game/station designs, sample HTML, identity references, and a large visual library. Individual Drive documents can change; use the linked original as the source of truth and record the version/date when importing a particular lesson or asset.

## Folder map

[Top-level Mowazi project folder](https://drive.google.com/drive/folders/1BSQkT99nOw8G-tBB2u83tGwxjuVJwGBS)

The folder guide describes six numbered areas: strategy/reference; curriculum by grade; games and stations; visual curriculum library and sample lessons; identity/experience reference; and change/archive records. Keep these categories distinct—strategy is not the curriculum map, a prototype is not an approved lesson, and an archive is not the current version.

## Import policy

- **Already brought into the repository:** this authoring/scope summary and this source index, so the structure, distinctions, review gates, and canonical source links travel with the code.
- **Import selectively:** small source briefs or approved lesson text needed by an implemented feature; only the visual assets used by that feature; preserve original attribution/source and review status.
- **Do not bulk mirror:** the 180-file visual library, 40 MB-class slide decks, compiled sample app bundles, unrelated research/market files, or all per-grade curriculum folders. Link to Drive unless a concrete implementation needs a specific file and its size/licensing/review status has been checked.
- **Do not promote drafts to facts:** current prototypes and draft material stay explicitly labelled. Mapping, content approval, age/accessibility review, and classroom trial are separate states.

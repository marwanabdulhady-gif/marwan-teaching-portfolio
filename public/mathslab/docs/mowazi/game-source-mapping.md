## Status vocabulary

- **Objective overlap (draft source):** the lesson text includes an objective matching some or all of the game's stated skill. This does not mean the game itself has been checked against every lesson outcome.
- **Partial / adjacent:** a nearby topic is documented, but scope, representation, grade-level detail, or the specific game objective does not match closely enough to claim alignment.
- **Unmapped:** no reviewed lesson objective for the game is recorded here. A possible search hit is not a source match.
- **Approval:** every entry remains an unapproved prototype. A source lesson marked P2 is a draft that still requires the later content, accessibility/design, classroom-trial, and owner-approval gates described in [`lesson-authoring-scope.md`](lesson-authoring-scope.md). No game in this ledger is represented as classroom-tested or curriculum-approved.

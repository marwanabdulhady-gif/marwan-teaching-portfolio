# 🎮 Fikr Lesson-Game Templates · K–12

One fill-in template per grade, from Kindergarten to Grade 12. Each has the same ten sections, tuned to the age:

1. **The grade profile** — reading load, input, rounds, feedback, failure, social, session, language, and the `BAND` switch.
2. **Topics by subject** — Maths, English, Arabic, Science, CS/AI.
3. **The one-page game brief** 🟨 — with a worked example for the grade.
4. **Three levels** — concrete → representational → abstract.
5. **Learn slides** — hook, model, your turn, Ghubar’s mistake.
6. **Feedback** — the hint ladder, Ghubar’s misconceptions, why-lines.
7. **The code** — a complete worked example game plus a blank skeleton.
8. **Accessibility** checklist for the age.
9. **Data, test and ship** — what to record, a Playwright test, the build steps.
10. **Quality bar** — score your game before you ship it.

**How to use:** copy the grade’s file, fill every 🟨, write the game from the skeleton in §7, run the test in §9.

**One rule across all grades:** *the mechanic is the thinking* — if a student can win without doing the skill, change the game.

The full kit reference (the round API `R`, Learn slides, engines, message contract, standalone mini-kit) is in **fikr-game-design-guide.md**.

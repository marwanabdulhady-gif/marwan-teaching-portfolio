Which continuity check fails first?
Print reference ·
  • Removed value: f(c) is undefined: the first condition fails, even though both limits equal 3.
  • Jump: The left and right limits differ (2 and 4), so the two-sided limit does not exist.
  • Moved value: Both limits equal 3, but f(c) = 1; the value does not match the limit.
  • Continuous case: The value exists, both limits equal 3, and f(c) = 3. All three conditions hold.

Polynomials · absolute value of polynomial expressions · sine and cosine of polynomial expressions.

Rational functions: denominator ≠ 0. Even-index radicals: respect the real domain. Odd-index radicals: continuous wherever defined.

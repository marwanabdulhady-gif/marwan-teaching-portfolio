Functions and Their Graphs

Function notation and evaluation, the difference quotient, domain, combining and composing functions, and even, odd, and piecewise functions.

Lesson overview

⌄

Functions are the language of calculus. In this lesson you'll pin down exactly what a function is, evaluate it with function notation, find where it is defined, and learn to build new functions by combining and composing old ones — then classify functions by their symmetry and handle piecewise, absolute-value, and step functions.

Explanation
Learning objectives

By the end of this lesson you should be able to:

  • Decide whether a relation is a function, including from a graph via the Vertical Line Test.
  • Use function notation to evaluate a function at numbers and at algebraic expressions.
  • Form and simplify the difference quotient f(x+Δx)−f(x)Δx\dfrac{f(x + \Delta x) - f(x)}{\Delta x}Δxf(x+Δx)−f(x)​.
  • Find the domain of a function involving radicals, rational expressions, and absolute values.
  • Combine functions by sum, difference, product, and quotient, and form composite functions.
  • Test a function for even or odd symmetry, and work with piecewise, absolute-value, and greatest-integer functions.

Before you start

  • Sketching graphs, intercepts, and symmetry (Lesson P1).
  • Factoring, and solving linear and quadratic equations and inequalities.
  • Interval notation for describing sets of real numbers.

Relations and functions

⌄

A relation is any set of ordered pairs (x,y)(x, y)(x,y). A function is a special relation: it pairs each input with exactly one output.

Definition

Function

A function fff from a set AAA to a set BBB is a rule that assigns to each element xxx in the domain AAA exactly one element yyy in BBB. Every function is a relation, but not every relation is a function.

So {(1,2),(2,3),(4,7)}\{(1, 2), (2, 3), (4, 7)\}{(1,2),(2,3),(4,7)} is a function — each input appears once — while {(1,2),(1,4),(2,6)}\{(1, 2), (1, 4), (2, 6)\}{(1,2),(1,4),(2,6)} is not, because the input 111 is paired with both 222 and 444.

Vertical Line Test
A graph represents yyy as a function of xxx exactly when no vertical line crosses it more than once. The parabola y=x2−1y = x^2 - 1y=x2−1 passes: every vertical line meets it once. A sideways parabola such as x=y2x = y^2x=y2 fails, since a vertical line can meet it twice.

Function notation and the difference quotient

⌄

Function notation names the rule and its input at once. Writing f(x)=x2+2x−3f(x) = x^2 + 2x - 3f(x)=x2+2x−3 means “the function fff takes an input xxx and returns x2+2x−3x^2 + 2x - 3x2+2x−3.” The symbol xxx is just a placeholder — you can substitute a number or an entire expression.

Worked example
For f(x)=x2+2x−3f(x) = x^2 + 2x - 3f(x)=x2+2x−3: f(0)=−3f(0) = -3f(0)=−3, f(−1)=1−2−3=−4f(-1) = 1 - 2 - 3 = -4f(−1)=1−2−3=−4, and substituting an expression, f(x+2)=(x+2)2+2(x+2)−3=x2+6x+5f(x + 2) = (x + 2)^2 + 2(x + 2) - 3 = x^2 + 6x + 5f(x+2)=(x+2)2+2(x+2)−3=x2+6x+5.

Substituting an expression powers the difference quotient — the average rate of change of fff over a step of width Δx\Delta xΔx. It is the algebraic engine behind the derivative you'll meet later.

f(x+Δx)−f(x)Δx,Δx≠0\frac{f(x + \Delta x) - f(x)}{\Delta x}, \quad \Delta x \neq 0Δxf(x+Δx)−f(x)​,Δx=0

Finding the domain of a function

⌄

The domain is the set of all inputs for which the function is defined. Unless a domain is stated, assume the implied domain: all real numbers that produce a real output. Two situations create restrictions:

  • Even roots: the radicand must be ≥0\ge 0≥0. For x−3\sqrt{x - 3}x−3​ require x−3≥0x - 3 \ge 0x−3≥0, so the domain is [3,∞)[3, \infty)[3,∞).
  • Denominators: never zero. For 1x−2\dfrac{1}{x - 2}x−21​ exclude x=2x = 2x=2.

Absolute values and odd roots accept every real input to those operations. Any restrictions inside their input expressions still apply.

Combining and composing functions

⌄

Two functions can be combined arithmetically. For fff and ggg, the sum, difference, product, and quotient are defined pointwise, and the domain of each is the intersection of the domains of fff and ggg (the quotient also excludes any input where g(x)=0g(x) = 0g(x)=0).

(f+g)(x)=f(x)+g(x),(fg)(x)=f(x)g(x), g(x)≠0(f + g)(x) = f(x) + g(x), \qquad \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)},\ g(x) \neq 0(f+g)(x)=f(x)+g(x),(gf​)(x)=g(x)f(x)​, g(x)=0

A more powerful combination is composition, which feeds the output of one function into another.

Definition

Composite function

The composition of fff with ggg is (f∘g)(x)=f(g(x))(f \circ g)(x) = f(g(x))(f∘g)(x)=f(g(x)). Its domain is the set of all xxx in the domain of ggg such that g(x)g(x)g(x) is in the domain of fff.

Worked example · Respect the order of composition

f(x)=x2,g(x)=x−1f(x)=x^2,\qquad g(x)=x-1f(x)=x2,g(x)=x−1

Even and odd functions

⌄

On a domain symmetric about zero, symmetry of a graph corresponds to an algebraic test on f(−x)f(-x)f(−x).

  • Even: f(−x)=f(x)f(-x) = f(x)f(−x)=f(x) — the graph is symmetric about the yyy-axis (e.g. x2−2x^2 - 2x2−2).
  • Odd: f(−x)=−f(x)f(-x) = -f(x)f(−x)=−f(x) — the graph is symmetric about the origin (e.g. x3−3xx^3 - 3xx3−3x).

Piecewise, absolute-value, and greatest-integer functions

⌄

A piecewise function applies different rules on different parts of its domain. The absolute-value function is the classic example — it is really two linear pieces joined at the point where the inside expression changes sign.

∣x−1∣={x−1x≥1−(x−1)x<1|x - 1| = \begin{cases} x - 1 & x \ge 1 \\ -(x - 1) & x < 1 \end{cases}∣x−1∣={x−1−(x−1)​x≥1x<1​

The greatest-integer (or floor) function f(x)=⌊x⌋f(x) = \lfloor x \rfloorf(x)=⌊x⌋ returns the greatest integer less than or equal to xxx, producing a staircase of horizontal steps — for example ⌊2.7⌋=2\lfloor 2.7 \rfloor = 2⌊2.7⌋=2 and ⌊−1.2⌋=−2\lfloor -1.2 \rfloor = -2⌊−1.2⌋=−2.

Common mistake. For negative inputs the floor rounds down, not toward zero: ⌊−1.2⌋=−2\lfloor -1.2 \rfloor = -2⌊−1.2⌋=−2, not −1-1−1.

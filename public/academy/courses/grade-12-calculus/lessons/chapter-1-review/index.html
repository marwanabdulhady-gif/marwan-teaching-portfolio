Part A · Graphical, numerical, and one-sided limits

⌄
Explanation

Understand the idea before the notation

A limit asks where the nearby outputs are heading as x approaches a target. Read the left side and the right side, then compare them. If both approach the same height, that height is the two-sided limit—even if the actual point is missing or placed somewhere else.

Mr. Marwan’s decision routine

Substitute first. A real number means you are done. The indeterminate form 0/0 is not an answer; it tells you to simplify. Factor polynomial expressions, use a conjugate for radicals, and reshape trigonometric expressions to match a known special limit. Then substitute again.

Part C · Continuity and discontinuities

⌄
Explanation

What continuity really means

At the point being tested, the function must have a value, the nearby behavior must approach one common value from both sides, and that approached value must equal the function value. If any one condition fails, the function is not continuous there.

Continuity at x = c

1. f(c) is defined (has a real value)1.\ f(c)\text{ is defined (has a real value)}1. f(c) is defined (has a real value)2. lim⁡x→c−f(x)=lim⁡x→c+f(x)2.\ \lim_{x\to c^-}f(x)=\lim_{x\to c^+}f(x)2. x→c−lim​f(x)=x→c+lim​f(x)3. lim⁡x→cf(x)=f(c)3.\ \lim_{x\to c}f(x)=f(c)3. x→clim​f(x)=f(c)

Classify the break

Removable: finite limit but a hole/wrong point. Jump: finite one-sided limits disagree. Infinite: at least one side is unbounded.

Piecewise breaking point

Ignore intervals where each formula is already continuous; test the point where the rule changes using LHL, RHL, and the assigned function value.

Closed interval [a,b]

Continuous inside (a,b)(a,b)(a,b), right-continuous at aaa, and left-continuous at bbb.

Absolute value

Rewrite around the zero of the inside expression when a piecewise analysis is needed.

Greatest integer function

Expect jumps at integers. One-sided values around an integer are essential for deciding continuity.
Make a piecewise function continuous
f(x)={2x+k,x<3x2−2,x≥3f(x)=\begin{cases}2x+k,&x<3\\x^2-2,&x\ge3\end{cases}f(x)={2x+k,x2−2,​x<3x≥3​

For continuity at 333, match the two pieces: 6+k=76+k=76+k=7, so k=1k=1k=1.

Part D · Intermediate Value Theorem and bisection

⌄
Explanation

Why IVT works

Picture a continuous curve drawn without lifting your pencil. If one endpoint is below a target y-value and the other is above it, the curve must cross that level somewhere between them. For a zero, the target is the x-axis.

Use IVT only after checking its hypotheses. If fff is continuous on [a,b][a,b][a,b] and a number NNN lies strictly between f(a)f(a)f(a) and f(b)f(b)f(b), then some c∈(a,b)c\in(a,b)c∈(a,b) satisfies f(c)=Nf(c)=Nf(c)=N.

f(a)f(b)<0⇒at least one zero in (a,b)(when f is continuous)f(a)f(b)<0\quad\Rightarrow\quad\text{at least one zero in }(a,b)\quad\text{(when }f\text{ is continuous)}f(a)f(b)<0⇒at least one zero in (a,b)(when f is continuous)
Bisection · narrow the zero
f(x)=x3+x−1,[0,1]f(x)=x^3+x-1,\qquad [0,1]f(x)=x3+x−1,[0,1]

First verify the sign change. Then evaluate the midpoint. Keep the half-interval whose endpoint values still have opposite signs. Repeat to produce a smaller interval containing a zero.

Common mistake. IVT guarantees existence under its conditions; it does not automatically tell you the exact zero or guarantee that there is only one zero.

Part E · Infinite limits and vertical asymptotes

⌄
Explanation

Hole or vertical asymptote?

A hole has a finite nearby height after cancellation. A vertical asymptote has unbounded nearby behavior because a denominator factor remains. That is why we factor before classifying a denominator zero.

Meaning

+∞+\infty+∞ and −∞-\infty−∞ describe unbounded behavior; they are not real-number limit values.

Vertical asymptote

x=cx=cx=c is a VA when at least one one-sided limit at ccc is +∞+\infty+∞ or −∞-\infty−∞.

Factor first

A denominator zero alone is not enough. Cancelled factor → investigate a hole. Factor remaining below → investigate a VA.

Sign routine

Near each candidate, determine the sign of every factor. The sign tells whether the branch goes to +∞+\infty+∞ or −∞-\infty−∞.

Multiplicity shortcut

Even denominator power keeps the same sign across the zero; odd power changes sign. Always account for the numerator sign.

Trig asymptotes

Rewrite as quotients: tan⁡x=sin⁡x/cos⁡x\tan x=\sin x/\cos xtanx=sinx/cosx and cot⁡x=cos⁡x/sin⁡x\cot x=\cos x/\sin xcotx=cosx/sinx, then inspect denominator zeros.
One question · three skills
f(x)=(x−2)(x+4)(x−2)(x−1)2f(x)=\frac{(x-2)(x+4)}{(x-2)(x-1)^2}f(x)=(x−2)(x−1)2(x−2)(x+4)​

At x=2x=2x=2, the common factor cancels → removable discontinuity. At x=1x=1x=1, an even denominator power remains → vertical asymptote with the same denominator sign on both sides; then use the numerator sign to determine the infinity direction.

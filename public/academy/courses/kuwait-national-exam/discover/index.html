BEFORE YOU JOIN

A few useful answers.

Know what you’re getting,
and how to get started.

Where should I start?+

Start with the course guide and the diagnostic. Use it to identify topics to revisit, then work through the lessons and practice before trying a timed mock.

Does the generator create brand-new questions?+

No. It selects questions from a finite reviewed bank and shuffles questions and answer choices. Questions can repeat; the tool does not create new numerical variants or AI-generated questions.

Are the reference forms official past papers?+

No official provenance is claimed. Mock-source and reconstructed-date reference forms are study resources, separate from active timed mocks. Questions can repeat across forms.

How does access work after payment?+

For new-student hosted checkout, the teacher verifies payment before activating course access. Keep your PayPal confirmation. If you are already signed in, access is linked to that student account automatically after successful PayPal capture. There is no promised activation time; contact the teacher if you need help.

Can I use my existing student account?+

Yes. Log in before paying so checkout uses your existing student account. If National Exam access is already active, go straight to the course instead of paying again.

Will this guarantee my exam result?+

No course can guarantee a score or admission. This is a structured preparation resource, not an official exam service. Use the topic list to judge its fit and check current exam requirements with the relevant exam provider.

    Greatest Integer Functions

    ⌄
    Interactive lab

    Greatest Integer Step Explorer

    Predict the greatest integer less than or equal to x. For negative inputs, move down the number line—not toward zero.

    The output k satisfies k ≤ x < k + 1. At an integer, the output is that integer itself.

    Print reference · At x = -0.7, floor(x) = -1, because -1 ≤ -0.7 < 0. Each step [k, k+1) has a closed left endpoint and an open right endpoint. For example floor(−0.7) = −1; floor(−1) = −1.
    Key takeaway

    Mr. Marwan’s graphing routine

    1. Find the subinterval length from the coefficient of x.
    2. Start subintervals from the zeros/boundaries of the inside expression.
    3. Place equality on the correct endpoint according to the direction of the x coefficient.
    4. Substitute the included endpoint to find the constant value on each step.

    Vertical Line Test Lab

    Predict how many points share this x-value, then check. A single line with two intersections disproves being a function; one passing line cannot prove it.

    Solid: relation. Dashed: test line. Window only; parabolas continue beyond it. Circle radius 2.5. Equal axis units.

    y = x²/4 − 2

    Print reference · y = x²/4 − 2. At x = 0.8, intersection count = 1; y = -1.84. The parabola is a function of x. The circle and sideways parabola are not: some x-values have two outputs. Curves are shown in a window; they are not truncated domains. Both axes have equal units.

    A graph represents y as a function of x if and only if no vertical line intersects the graph more than once.

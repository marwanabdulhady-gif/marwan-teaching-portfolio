Data Sufficiency: Is the Information Sufficient?

An adult-focused pilot of GMAT Data Sufficiency. Practice and simulation use different original questions.

Teacher presentationA wider view for teaching, with the same lesson sections and examples.

Decide sufficiency, not the answer

In Data Sufficiency you are not being asked to calculate every possible value. Decide whether the given information produces one definite answer to the question.

Step 1 · Test independently

Ignore statement (2) while testing (1), then ignore (1) while testing (2).

Step 2 · Combine only if required

If neither statement alone is sufficient, check whether they work together. Do not combine them too early.

Data Sufficiency · Decision Mind Map

Follow the branches in order. Answer A–E according to what is sufficient, not according to the numeric result.

For Yes/No questions, a definite NO is sufficient too. Never combine the statements before checking each independently.

Worked Example · Is x uniquely determined?

Statement (1): x + 4 = 12. Statement (2): 3x = 24.

Each statement independently fixes x = 8, so the answer is D (each alone sufficient).

Common traps

A statement that suggests a likely answer is not sufficient. A Yes/No question is sufficient when it produces an unambiguous Yes or an unambiguous No. The goal is certainty, not necessarily a numerical value.

Data Insights: Mixed Interpretation and Reasoning

Build the concept, interpret evidence, and apply it in a separate assessment pool.

Teacher presentationA wider view for teaching, with the same lesson sections and examples.

Learn: Evidence and decisions

Mixed review is a practice organization, not a sixth GMAT format

The current GMAT Data Insights section uses five formats: Data Sufficiency, Table Analysis, Graphics Interpretation, Multi-Source Reasoning, and Two-Part Analysis. A mixed lesson can combine skills for review, but each question should still use one of those response formats.

Map each claim to its evidence source

A table may provide counts, a chart may show trend, and a note may define the target. Record which source supports each quantity; use only evidence relevant to the claim.

Match the denominator and time period

Rates require a numerator and its corresponding population. Compare like periods and distinguish an observed value from a forecast or target.

Use the calculator as a checking tool when arithmetic warrants it

The exam’s on-screen calculator is available in Data Insights. Set up the relationship and estimate the expected magnitude first; use the calculator for arithmetic that is cumbersome, then interpret the result in context. It does not decide which denominator or evidence is relevant.

Mixed practice combines the five formats

This lesson is not a sixth GMAT format. It brings together Data Sufficiency, Table Analysis, Graphics Interpretation, Multi-Source Reasoning and Two-Part Analysis so that you practise choosing the right method when the format changes.

Use the calculator after choosing the method

An on-screen calculator is available in Data Insights. First identify the required operation, units and denominator; then use it when arithmetic would take longer or risk an error. Calculator availability does not make every question a calculation question. No calculator is available in Quantitative Reasoning.

Identify the requested operation first

Determine whether the item asks for sufficiency, True/False judgments, chart completion, source synthesis, or two linked choices.

Match evidence to the claim

Use the relevant source, row, axis, unit and denominator. Ignore plausible facts that do not answer the question.

Complete the response format

A case can require several decisions. Check each selection, and verify that linked responses work together.

Learning Objectives

  • Identify which of the five current DI item formats governs the response interface.
  • Connect evidence across tables, charts, and written notes while preserving each source’s scope.
  • Separate observed results, forecasts, and definitions before making a conclusion.
  • Recognize the response format and evidence structure in all five DI question types.
  • Choose calculations and denominators that match the exact prompt.
  • Complete every response in a multi-part item using only supplied evidence.

Prerequisite Knowledge

  • Read numerical tables and common graph types.
  • Calculate ratios, percent changes, and weighted rates.
  • Recognize Data Sufficiency, Table Analysis, Graphics Interpretation, Multi-Source Reasoning, and Two-Part Analysis response patterns.
  • Fractions, percentages and ratios.
  • Reading tables, graphs and short data passages.

Worked Examples

Data Sufficiency: test a property, not a value

Is integer n divisible by 6? Statement (1): n is divisible by 2. Statement (2): n is divisible by 3.

  1. A multiple of 2 need not be a multiple of 6; a multiple of 3 need not be a multiple of 6.
  2. Together the coprime divisibility conditions guarantee divisibility by 6.

Conclusion: Neither statement alone is sufficient; together they are sufficient.

Table Analysis: derive before comparing

A table lists revenue and cost for three regions. Determine which has the greatest profit and whether East’s margin exceeds North’s.

  2. Margins are North 20%, South 25%, East 25%; East exceeds North because 25% is greater than 20%.

Conclusion: South has the greatest profit, and East’s margin is greater than North’s.

Graphics Interpretation: read the chart scale

A pie chart shows A=30%, B=45%, C=25% of 400 units. Find B’s quantity and A+C.

  1. Multiply the total by B’s share: 0.45 × 400 = 180.
  2. Add A and C shares: 30% + 25% = 55%; 0.55 × 400 = 220.

Conclusion: B represents 180 units; A and C together represent 220 units.

Multi-Source Reasoning: normalize by the correct total

North completed 160 of 200 orders; South completed 180 of 240. Compare completion rates.

  1. Use completed orders divided by submitted orders for each region.
  2. North is 80%; South is 75%, so North has the higher completion rate.

Conclusion: South has more completed orders, but North has the higher rate.

Two-Part Analysis: select a consistent pair

Two plans cost 40+3n and 20+5n dollars. Find the break-even quantity and total.

  1. Set the cost expressions equal: 40+3n=20+5n, so n=10.
  2. Substitute: 40+3(10)=70 dollars.

Conclusion: The pair is 10 units and $70.

Think Like a GMAT Test-Taker

Classify the required response before solving; use the matching official item format.

Build a short evidence map: claim → source → relevant values → operation.

Write units and denominators beside values, especially when switching between counts and rates.

Estimate first; use the DI calculator only for arithmetic that benefits from it.

Check that every conclusion is supported by the stated evidence, not by a forecast or outside assumption.

Common Traps

Treating mixed review as an additional official DI question type.

Combining rates by taking an unweighted mean when group sizes differ.

Comparing a forecast with an actual as though both were measured outcomes.

Using a calculator before identifying the correct inputs or denominator.

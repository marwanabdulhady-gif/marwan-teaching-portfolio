Real Number System · classify from smallest family

⌄

A rational number can be written as a ratio of integers. Terminating and repeating decimals are rational. Nonterminating, nonrepeating decimals are irrational.

Union & Intersection · OR versus BOTH

⌄

Explanation

Exam Strategy · translate before you calculate

⌄
Key takeawaySTEP 1
Identify the representation

Set, roster, set-builder, interval, inequality, or number line?

Key takeawaySTEP 2
Translate carefully

Open/closed endpoints and integer restrictions change the set.

Key takeawaySTEP 3
Choose the operation

Union means OR; intersection means BOTH; complement uses U.

Key takeawaySTEP 4
Check the result

No repeated roster elements; distance nonnegative; infinity never closed.

Common mistakeMixed-representation warning

A finite set such as {−4,−2,0,1,3,5,7}\{-4,-2,0,1,3,5,7\}{−4,−2,0,1,3,5,7} is not an interval. Test its individual elements against the interval before taking union or intersection.

Related Rates · Connect the Changes

Different quantities can change at the same instant. Build the model first, differentiate with respect to time, then use the instant data to find the rate you need.

Model changing quantities, differentiate with respect to time, and solve real-life rate problems using the teacher routine.

Mr. Azzam’s core idea

1 · Model the situation

Name changing quantities, rates, signs, and the equation connecting them.

Mr. Azzam’s 10-step routine

⌄
STEP 1
Read & pull out information
Identify what changes and what formula can connect the quantities.
STEP 2
Sketch a diagram
Build a model whenever the geometry matters.
STEP 3
Write Known & Wanted
Name the given rate and exactly which rate is required.
STEP 4
Check the signs
Increasing is positive; decreasing is negative.
STEP 5
Constant or varying?
A fixed length stays constant; a changing length is a function of time.
STEP 6
Set up the equation
Relate only the quantities needed for the problem.
STEP 7
Differentiate in time
Differentiate with respect to ttt before inserting instant values.
STEP 8
Plug in known items
Now use the instantaneous values and signed rates.
STEP 9
Solve the wanted rate
Keep the requested derivative visible and isolate it.
STEP 10
State units + direction
Finish with a rate unit and interpret the sign when appropriate.

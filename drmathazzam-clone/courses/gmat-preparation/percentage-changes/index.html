Discover the concept

A 20% increase followed by a 20% decrease does not restore the original value, because the second percentage is calculated from a different base.

3 · Worked example: unequal percentage changes

A company has 200 customers. Its customer count increases by 20% in the first month, then decreases by 20% in the second month. How many customers remain after the second month?

200(1+0.20)(1−0.20)=200(1.2)(0.8)=192

Think Like a GMAT Test-Taker

Identify the base quantity, then translate each percentage into a multiplier before computing.

The faster method

For successive +a% and +b% changes, the overall increase is a + b + ab/100 percent. For +p% then -p%, the overall loss is p²/100 percent.

Decision rule

When the original value is missing, divide the final value by the product of the multipliers; never reverse a discount by simply adding the percentage.

Common GMAT Traps

  • Adding consecutive percentage changes instead of multiplying factors.
  • Assuming +20% followed by -20% gives zero net change.
  • Applying a discount to the original base after an earlier increase.
  • Confusing a percentage-point change with a percentage change.
